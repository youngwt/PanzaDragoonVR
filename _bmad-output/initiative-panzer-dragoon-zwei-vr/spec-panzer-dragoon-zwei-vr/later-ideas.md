# Later ideas

Out of scope for the demo (milestones 0 to 7). Recorded so they are not rebuilt from memory or pulled in early.

| Area | Idea |
|------|------|
| Health | Shown as the dragon's colour or aura, not a bar. Controller vibrates on each hit |
| Berserk | The dragon's own pent-up energy. Builds as energy fizzing around the controllers; released by a button press |
| Steering | Right thumbstick guides the dragon within its rail |
| View turns | Seated swivel-chair play. Left stick gives quick, smooth 90-degree turns as an alternative, as Rez Infinite does |
| Handedness | Aiming hand selectable, left or right |
| Radar | Kept as the one HUD element; revisit its form in the headset |
| Music | A soundtrack MP3 supplied by the player |
| Sound effects | Extracted from the disc if possible: gun firing, dragon hit, target hit. Each plays from its source: the gun in hand, the dragon beneath, the target's position |
| Enemy motion | Real flight paths in place of corkscrews |
| Enemies | Giant centipedes, then the final boss |
| Release | The APK bundled with the extraction tool. The user sideloads the APK and copies extracted assets to the headset with SideQuest |
